# Student Tracker

A Dart project for tracking student marks and generating report cards.

## Project Structure

- `bin/` — Dart programs and tasks.
- `lib/` — Main student tracker library.
- `test/` — Unit tests.
- `pubspec.yaml` — Project configuration and dependencies.

## Getting Started

Make sure Dart is installed, then run the project from the project directory:

```bash
dart run bin/student_tracker.dart
```

## Testing

Run the unit tests using:

```bash
dart test
```
